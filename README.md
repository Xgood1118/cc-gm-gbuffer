# G-Buffer 打包与精度

一个把法线、粗糙度、材质编号打包进有限位宽、并能无损解包的 G-Buffer 编解码器。
纯 Python 标准库实现，无第三方依赖。

## 保留签名

- `GBuffer`
- `pack_pixel(normal, rough, mat)`
- `unpack_pixel(packed)`
- `measure_error(orig, back)`

## 位布局

**32 位整包**（`pack_pixel` / `unpack_pixel`）：

| 位段      | 通道     | 编码                                   |
|-----------|----------|----------------------------------------|
| [15:0]    | 法线     | 八面体编码，u/v 各 8 位（254 级，0 精确可表示），解包后重新归一化 |
| [23:16]   | 粗糙度   | 8 位，[0,1] 均匀量化                    |
| [31:24]   | 材质编号 | 8 位整数原样存放，精确往返、不量化       |

**半精度整包（64 位）**（`pack_pixel_half` / `decode_half`）：法线三个分量各 16 位
IEEE 754 binary16（bits [47:0]），粗糙度 8 位，材质编号 8 位。

**位宽不足时的分配优先级**（`allocate_bits`）：材质编号优先拿满（必须精确往返），
剩余位全部给粗糙度。

## 误差上界（各通道独立位域，互不污染）

| 通道   | 上界 | 说明 |
|--------|------|------|
| 法线（32 位整包） | **≤ 0.9570°** | `2·asin(3 / (√2·(2ⁿ−2)))`，n=8；推导：解码映射 Lipschitz 常数 ≤ 3，(u,v) 量化位移 ≤ √2·eps |
| 法线（半精度）    | **≤ 0.0969°** | 分量舍入 ≤ 2⁻¹¹，`2·asin(√3·2⁻¹¹)`；严格比 32 位整包更紧 |
| 粗糙度（8 位）    | **≤ 0.5/255 ≈ 0.001961** | 均匀量化半步长 |
| 材质编号          | **0** | 不量化，完全往返 |

## 边界行为（确定性）

- 零长度（或非有限）法线：按 `(0, 0, 1)` 处理，两次打包结果一致。
- 粗糙度越界：截断到 `[0, 1]`。
- 材质编号越界（负或 ≥ 2^material_bits）：抛 `ValueError`。

## 布局协商

`negotiate_layout(candidates, max_error_deg, max_bytes)` 按法线角度误差上界与
总带宽上限挑选布局，返回 `{"selected": 索引或 None, "rejected": [(索引, 理由码)]}`：

- `E_ERROR`：法线角度误差上界超限
- `E_BANDWIDTH`：总带宽超限

可行布局中选误差上界最小者（并列取带宽更小、索引更小者）。

## 解码对齐

`pack_aligned` / `decode_aligned` 在负载高位附加 8 位布局标签。`decode_aligned`
遇到超出布局总位宽的位、标签不符或位宽不一致时一律抛 `ValueError`，
绝不静默取零或让越界位污染任何通道。

## 实测数据（CLI 验收输出）

```
== G-Buffer 验收 ==
像素数: 2 -> packed.json
32 位整包:  法线误差上界 0.9570° | 文件实测 0.3786° | 采样实测 0.9395°
半精度整包: 法线误差上界 0.0969° | 文件实测 0.0112° | 采样实测 0.0228°
粗糙度: 上界 0.001961 | 文件实测 0.001961
布局协商: selected=1 rejected=[(2, 'E_ERROR'), (3, 'E_BANDWIDTH')]
```

- 采样实测：对 20000 个斐波那契球面均匀方向做打包-解包的最大角度误差。
- 半精度采样实测 0.0228°，比 32 位整包实测 0.9395° 紧一个数量级以上。
- 布局协商：候选 `{16,8,8}`、`{20,6,6}`、`{10,11,11}`、`{40,16,16}`，
  约束 ≤ 2.0° 且 ≤ 8 字节，选中 1 号（`{20,6,6}`，上界 0.2379°），
  2 号因误差超限（8.1096°）、3 号因带宽超限（9 字节）被淘汰。
