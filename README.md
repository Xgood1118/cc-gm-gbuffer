# G-Buffer 打包与精度

一个把法线、粗糙度、材质编号打包进有限位宽、并能无损解包的 G-Buffer 编解码器。
只使用 Python 标准库。

## 保留签名

- `GBuffer(normal, rough, mat)`
- `pack_pixel(normal, rough, mat) -> int`
- `unpack_pixel(packed) -> {"normal": tuple, "rough": float, "mat": int}`
- `measure_error(orig, back) -> {"angle_deg", "angle_rad", "rough_abs", "rough_error", "mat_exact"}`

## 位布局（32 位整数）

| 字段 | 位区间 | 位数 | 编码 |
| --- | --- | --- | --- |
| 粗糙度 rough | 0–5 | 6 | 均匀量化，步长 1/63 |
| 材质编号 mat | 6–13 | 8 | 无损整数，0–255 |
| 法线方位角 φ | 14–22 | 9 | 均匀量化，步长 2π/512 |
| 法线极角 θ | 23–31 | 9 | 均匀量化，步长 π/511，θ = acos(z) |

法线固定占 18 位（方位角 + 极角）。解包时由 φ、θ 重建向量，并**显式重新归一化**，
返回的始终是单位向量。

### 剩余位分配优先级

总位宽减去法线位后剩余 14 位，由材质编号与粗糙度共用。优先级是
**材质编号 > 粗糙度**：

1. 材质编号先拿满 8 位，保证 0–255 全部无损往返、不被量化；
2. 余下 6 位给粗糙度。

若配置的总位宽连材质编号都放不下，分配函数 `_allocate_remaining_bits` 直接抛出
`ValueError`，而不是悄悄量化材质编号——即“材质编号无损”这一条不可降级。

## 误差上界（理论上界，非经验值）

| 通道 | 上界 | 推导 |
| --- | --- | --- |
| 法线夹角 | **≤ 0.5277°**（`NORMAL_MAX_ANGLE_DEG`） | 球面两点夹角 ≤ ‖Δφ‖₁；方位角半步 π/512，极角半步 π/1022，求和 |
| 粗糙度 | **≤ 0.00794**（`ROUGH_MAX_ERROR`） | 均匀量化步长的一半，1/(2·63) |
| 材质编号 | **0**（完全无损） | 8 位整数编码 0–255 |

`measure_error` 返回的法线角度用 `atan2(|n×n'|, n·n')` 计算，数值稳定，不受
浮点精度影响。各通道独立量化、独立掩码，误差不会互相污染。

## 边界行为

三种边界输入都有确定结果：

| 输入 | 行为 |
| --- | --- |
| 法线长度为 0 | 确定性回退为 `(0, 0, 1)`；`measure_error` 也按该回退法线比较，角度误差为 0 |
| 法线分量非有限（NaN/±inf） | 抛 `ValueError`（没有确定方向） |
| 法线非单位长度 | 打包前归一化，等价输入得到相同打包结果 |
| 粗糙度 < 0 或 > 1 | 饱和到 0 或 1；±inf 同理 |
| 粗糙度为 NaN | 抛 `ValueError` |
| 材质编号 < 0 或 > 255 | 饱和到 0 或 255；`measure_error` 的 `mat_exact` 为 `False` |
| 材质编号非整数（含 `3.0`、`"3"`） | 抛 `TypeError` |

打包是纯函数：同一输入重复调用得到相同的整数；等价输入（未归一化的法线、
整数分量）也得到相同结果。

## 实测结果

命令：

```
python -m pytest tests -q
python -m gbuffer.cli data/pixels.json --out packed.json
```

`data/pixels.json` 共 2 个样本，`packed.json` 中的统计：

| 指标 | 结果 | 上界 |
| --- | --- | --- |
| 最大法线角度误差 | **0.354278°** | 0.527688° |
| 最大粗糙度误差 | **0.007937** | 0.007937 |
| 材质编号往返一致数 | **2 / 2** | 2 / 2 |
| 越界样本数 | **0** | — |

`pytest`：29 passed。

> 注：pytest 是测试工具的依赖，运行时库本身只用标准库。
> 注意“越界样本数”按解析后的数值判定（如 `256`、`-1`、`0.0` 法线）；
> 例如若某样本的材质编号是 `256`，它会被计入越界，同时 `mat_exact` 为 `False`。
