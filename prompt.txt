在现有 gbuffer 骨架上，把它做成一个把法线、粗糙度、材质编号打包进有限位宽、并能无损解包的 G-Buffer 编解码器。保留 GBuffer、pack_pixel、unpack_pixel、measure_error 的现有名字与签名，
只用 Python 标准库，不得引入第三方依赖，不得改动 data/pixels.json。

## 需要完成

1. **打包**
   - 法线占固定位数，解包后要重新归一化，最大角度误差写进 README 上限。
   - 粗糙度与材质编号共用剩余位数，位数不足时要按明确优先级分配。
2. **精度**
   - 解包后的每个通道误差都要有上界，且不能随通道相互污染。
   - 材质编号必须能完全往返，不能被量化。
3. **边界**
   - 输入法线长度为 0、粗糙度越界、材质编号越界三种情况都要有确定结果。
4. **输出**
   - 打包结果两次一致。

## 测试

- 覆盖：法线角度误差上界、材质编号无损、越界输入、通道互不污染、两次一致。
- `python -m pytest tests -q` 全部通过。
